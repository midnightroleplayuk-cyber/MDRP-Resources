## ⌨️ How to Set Up & Use Keybinds (Native FiveM Keybinds)

CoreFx Admin Panel uses **Native FiveM Keybinds**, meaning you do **NOT** need to configure or save keys inside any script UI or database! All keybinds are managed directly through your GTA V / FiveM client settings.

### 🎮 How to change your menu hotkeys:
1. Open your GTA V / FiveM **Pause Menu** (`ESC`).
2. Go to **Settings** > **Key Bindings** > **FiveM**.
3. Scroll down until you see **CoreFx Admin** (or the respective action names).
4. Click on the action you want to bind (e.g., *Open Admin Panel*, *NoClip / Ghost Mode*, *Vehicle Repair*).
5. Press any key or mouse button on your keyboard/mouse (e.g., `F10`, `NUMPAD 1`, `MOUSE 4`) to assign it!

### 💡 Why is this better?
- **Zero Lag & No DB Spam:** No saving to databases or JSON files; FiveM handles your bindings natively at 0.00ms CPU cost!
- **Live Auto-Detection:** The menu instantly detects whatever key you bind in your settings and displays it live in the UI!
- **Unbound Protection:** If you haven't assigned a key yet, the UI will cleanly display **"UNBOUND"** (in gray) so you know exactly which actions need a shortcut.
