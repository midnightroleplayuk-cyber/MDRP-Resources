INSTALLATION
1. Extract qbox_custom_peds folder into your server resources directory.
2. Add 'ensure qbox_custom_peds' to server.cfg.
3. Restart server.

PED MODEL NAMES
ig_abby
ig_gordon_ramsay
ig_gordon_ramsay_casual

These are streamed ped models, not selectable player outfits by default.
Use your admin ped menu or player model selection script to select the model.
