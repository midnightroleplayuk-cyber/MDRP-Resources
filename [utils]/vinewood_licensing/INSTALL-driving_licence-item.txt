================================================================
PROVISIONAL LICENCE (added)
================================================================

1) Add a second item to ox_inventory/data/items.lua:

    ['provisional_licence'] = {
        label = 'Provisional Driving Licence',
        weight = 10,
        stack = false,
        close = true,
        consume = 0,          -- REQUIRED: a licence is not used up when shown
        consume = 0,          -- REQUIRED: a licence is not used up when shown
        description = 'Provisional entitlement - must be accompanied',
        client = {
            image = 'driving_licence.png',
            export = 'vinewood_licensing.useLicence'
        }
    },

   (Uses the same export as the full licence - one export serves both items.)

2) Photo storage via Fivemanage:

   - Install screenshot-basic (https://github.com/citizenfx/screenshot-basic)
     and ensure it before vinewood_licensing.
   - Create an API token at fivemanage.com.
   - Paste it into server/config.lua:

        Config.Fivemanage = {
            ApiKey = 'YOUR_FIVEMANAGE_TOKEN'
        }

   server/config.lua is a server_script, so it is never sent to clients.
   (A 'fivemanage_key' convar still works as a fallback if you prefer it.)
   If screenshot-basic is missing or the token is unset, the provisional is
   still issued - it just falls back to the live in-game mugshot on the card,
   and a warning is printed in the server console.

3) Settings live in shared/config.lua under Config.Provisional
   (price, payment account, whether it's required before exams, camera
   distance/FOV for the photo booth, countdown length).
