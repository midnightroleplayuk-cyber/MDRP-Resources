MM Radio Qbox three-tab overhaul
- Primary / Secondary / Settings tabs, each frequency tab with named quick presets.
- Presets are read from shared/shared.lua Shared.RadioNames; server-side restrictions remain enforced.
- Same-channel cross-radio guard remains in existing Lua, with additional UI validation.
- Per-character name, overlay visibility, opacity and radio volume persist in FiveM resource KVP.
- Drag radio roster while the radio is open; existing saved position is retained.
- Talking indicator job colours are unchanged.
- The original compiled UI is preserved behind the new panel for compatibility.
- Radio UI is designed for 15vw width, with a 225px minimum for smaller resolutions.
Install: back up the existing mm_radio directory, replace with this folder, restart resource.
Note: no live Qbox/pma-voice runtime was available for integration testing.
