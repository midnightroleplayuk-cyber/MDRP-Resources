MIDNIGHT RADIO v6.18

1. Stop the server or stop mm_radio.
2. Remove the old mm_radio resource folder (do not run both).
3. Install this midnight_radio folder into your resources directory.
4. Change server.cfg from ensure mm_radio to ensure midnight_radio.
5. Update any inventory item or other resource references that explicitly target the old resource name.
6. Start/restart midnight_radio.

Compatibility: Internal mm_radio:* network event names remain unchanged to avoid breaking integrations. This is intentional. Existing radio items and item names have not been renamed.

IMPORTANT: FiveM resource KVP storage is scoped to resource name. Existing settings saved under mm_radio may not automatically transfer to midnight_radio. Back up the old resource data and have players verify their saved radio name and preferences after the rename.
