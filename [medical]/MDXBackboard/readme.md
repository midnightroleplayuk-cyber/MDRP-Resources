# Installation
- Install ox_lib  https://github.com/overextended/ox_lib to your server
- Drag "MDXBackboard" into your resources folder and add "ensure MDXBackboard" to your server.cfg
- Install https://www.gta5-mods.com/maps/medical-prop-pack  as it holds the prop used.



# Usage
- For QBCore and TMC simply use the item defined in your COnfig.lua, select a target by pressing [E], a yellow circle will show above a target. /removebackboard to take someone off a backboard
- For Standalone use the command defined in your COnfig.lua and then select target.
