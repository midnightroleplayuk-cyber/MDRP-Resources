# Installation
- Install ox_lib  https://github.com/overextended/ox_lib to your server
- Drag "MDXBvm" into your resources folder and add "ensure MDXBvm" to your server.cfg
- If you are using InteractSound please add the bvmSqueeze.ogg file to Interact-Sound/html/client/sounds
- If you are using TMC please add the bvmSqueeze.ogg file to your core_game/html/client



# Usage
- For QBCore and TMC simply use the item defined in your COnfig.lua, select a target by pressing [E], a yellow circle will show above a target.
- For Standalone use the command defined in your COnfig.lua and then select target.
