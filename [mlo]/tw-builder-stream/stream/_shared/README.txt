Shared assets — do not delete this folder.

  types/          Every .ytyp / .ymf definition. Deleting one stops unrelated
                  regions from loading their props.
  anim/           Animations used by all jobs.
  map_mainzone/   Terrain edits for the Grapeseed construction area. SIX
                  regions sit in that area (1, 2, 4, 5, 6, 7), so these files
                  are not tied to a single region. Delete them only if you are
                  removing all six, or if an MLO of yours clashes there — the
                  jobs keep working either way, the ground returns to vanilla.
