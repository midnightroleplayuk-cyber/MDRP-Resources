# redmo-firestation

A simple redesign of the original GTAV firestation map for FiveM. Updated interior and fully automatic doors.

## Features
- Modern interior
- Working automatic doors
- Clean lighting and prop setup
- Plug-and-play FiveM support

## Installation
1. Drop the "redmo-firestation" folder into your server's `resources` directory.
2. Add this to your server.cfg:
   ensure redmo-firestation
