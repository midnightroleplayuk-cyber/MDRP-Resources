# Third-party notices

RHS Burton Hospital contains the components below. Each entry says what is actually included and what is only
referred to, because those carry different obligations.

---

## Grand Theft Auto V game files (included, edited)

Owned by Rockstar Games / Take-Two Interactive. `stream/vanilla/` contains edited copies of the GTA V files for
the Burton tile: the tile's ymap files, the lod light ymaps, an occluder ymap, edited drawables (`.ydr`, `.ydd`)
and collision (`.ybn`). They are changed so the hospital can replace the Burton Los Santos Customs, and are
included only for that purpose. Rockstar's rights and terms apply to them. `compatibility/README.md` lists every
file by name.

The hospital also places stock GTA props, doors and textures **by name**. Those are not included in this package;
your game provides them.

---

## Vertex Hub (not included)

A merge tool for resources that override the same GTA files. Nothing from it is bundled or required. The files
that can clash are left unencrypted in `stream/vanilla/` so it can merge them.

---

## Everything else

The interior, exterior, props, textures, signage and scripts are original work of No BS Scripts, and the logo and
the name "Royal Health Service" are fictional.
