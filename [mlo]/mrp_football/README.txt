Sclessin 2020 - FiveM map resource

Install:
1. Extract the sclessin2020 folder into your server's resources folder.
2. Add `ensure sclessin2020` to server.cfg.
3. Restart the server.

This package streams the supplied original GTA V map assets and registers its YTYP.
It has not been tested in a running FiveM server. Ensure you have permission to use these assets.
