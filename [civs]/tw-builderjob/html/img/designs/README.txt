Design thumbnails for the /tw_bp Designs tab.

One picture per blueprint design (DESIGN_L_2F.png ...), produced by /permshoot:
the real construction layout is spawned in the sky, photographed, then cut to a
transparent PNG by tools/cut_house_shots.py.

The card falls back to the slab floor-plan diagram when the photo is absent, so
an empty folder is a working folder.
